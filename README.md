# Neuron Innovations landing page

This folder contains the `app` files for the first Neuron Innovations Next.js landing page.

## Setup

1. Create a Next.js app using the App Router and TypeScript:
   `npx create-next-app@latest neuroninnovations`
2. Replace the generated `app/page.tsx`, `app/globals.css`, and `app/layout.tsx` with the files in this folder.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Logo integration

The current design uses a temporary "N" brand mark. Once the square and horizontal Neuron Innovations logos are available, place them in `public/` and replace the temporary brand markup with the provided artwork.

## Contact

The page intentionally leaves the company contact method unset. Replace the note in the contact section with the preferred company email/contact form/social links.
